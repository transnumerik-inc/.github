## 🤝 Guide de contribution

Nous accueillons les contributions de la communauté ! Si vous souhaitez participer au développement de TransNumerik, suivez ces étapes :

### Avant de commencer
1. 🍴 Forkez le repository
2. 📋 Lisez la documentation du projet
3. 🐛 Vérifiez les issues existantes pour éviter les doublons

### Processus de contribution
1. **Créez une branche** pour votre fonctionnalité
   ```bash
   git checkout -b feature/ma-nouvelle-feature
   ```

2. **Effectuez vos modifications** en respectant les standards du projet

3. **Testez vos changements** localement

4. **Commitez avec des messages clairs**
   ```bash
   git commit -m "feat: description claire de la modification"
   ```

5. **Poussez votre branche**
   ```bash
   git push origin feature/ma-nouvelle-feature
   ```

6. **Créez une Pull Request** avec une description détaillée

### Standards de code
- Respectez les conventions de nommage du projet
- Ajoutez des commentaires pour les portions complexes
- Écrivez ou mettez à jour les tests si nécessaire
- Assurez-vous que le code passe les vérifications automatisées
